# 🚀 AI-Powered Smart Job Vacancy Finder System

An intelligent, next-generation AI-driven job vacancy matching and recruitment automation platform built with modern web technologies and **Supabase PostgreSQL**.

---

## 🌟 Core Features

- 🎯 **AI Natural Language Job Search & Prompt Matching**: Instant semantic job search and neural compatibility ranking.
- 📄 **ATS-Optimized Resume Builder & Live PDF Canvas**: Real-time resume synchronization, scoring diagnostics, and one-click standard A4 PDF download.
- 🧭 **AI Career Growth Advisor & Milestone Roadmap**: Interactive multi-phase career roadmap with real-time milestone checklists and salary benchmarks.
- 🎯 **ATS Keyword Diagnostic Scanner**: Match vs. gap keyword analysis with 1-click `+ Add to Profile` skill synchronizer.
- 🔖 **Cloud-Persisted Saved Jobs (Bookmarks)**: Instant bookmarking synchronized with Supabase `saved_jobs` table.
- 💬 **Direct Recruiter & Candidate Chat**: Embedded real-time messaging pipeline for hiring discussions.
- 💼 **Recruiter & Super-Admin Management Dashboards**: Full job vacancy lifecycle management, candidate pipeline tracking, and audit metrics.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3 (Modern Glassmorphism & Responsive Design)
- **Icons & Typography**: FontAwesome 6, Google Fonts (Outfit, Plus Jakarta Sans)
- **Backend / Database**: Supabase (PostgreSQL, Row Level Security, Realtime APIs)
- **PDF Generation**: html2pdf.js / Native Print Engine

---

## 🚀 Getting Started

1. Clone or download the repository.
2. Configure your Supabase Database using the provided [`supabase_setup.sql`](./supabase_setup.sql).
3. Open `index.html` in your browser or run a local static server:
   ```bash
   npx serve .
   ```
